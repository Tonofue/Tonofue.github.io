Privacy Policy — muse-drive-uni

Effective date: November 6, 2026

muse-drive-uni is a private, single-user application operated by Rikiya Tono ("the operator") for his own personal use. This policy explains what Google user data the application accesses, and how it is used, stored and shared.

Data accessed

With the owner's authorization, the application accesses the owner's own university Google account data through Google APIs:

  • Google Drive files and folders (view, download, create, update, rename, move, and move to trash), including files in Google Docs, Sheets, Slides and Forms formats, and Google Forms responses (read-only).
  • Gmail messages (read-only: list, search and read message content).
  • Google Calendar calendars and events.
  • Google Tasks task lists and tasks.
  • Google Contacts (People API) connections.

How the data is used

The data is used only to provide the owner with personal-assistant functions on his own computer: finding and organizing his own files, reading his own mail, checking his schedule and tasks, and editing his own documents at his request. The data is not used for advertising, profiling, or any purpose unrelated to the owner's own requests.

Storage and protection

OAuth credentials (refresh token) are stored only on the operator's own computer (a private virtual machine), in a file restricted to the owner account (file mode 600). Data retrieved through the APIs is processed on the operator's own computer. The application has no server that collects data from any other person, because the operator is the only user.

Sharing

Google user data accessed by this application is not sold, rented, or shared with any third party, and is not transferred to any other application, except the data transfers strictly necessary to call Google APIs themselves. No human other than the operator reads the data.

Limited Use disclosure

muse-drive-uni's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and deletion

The owner can revoke this application's access at any time at myaccount.google.com/permissions, and can delete the locally stored credentials from his own computer, which permanently ends the application's access. Upon request via the contact below, any locally retained copies of the owner's data handled by this application will be deleted.

Contact
